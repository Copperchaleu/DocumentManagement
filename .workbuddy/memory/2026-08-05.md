## BugFix：项目内容编辑器工具栏按钮大量缺失（compose-editor-toolbar）
- 现象：切到 wangEditor default 模式后，工具栏只剩 headerSelect/字体/字号/粗体/斜体/下划线几个按钮，颜色/列表/引用/对齐/链接/撤销重做全部消失。
- 根因：上一步（compose-editor）工程师把删除线菜单 key 误写成 `'strikeThrough'`（非法 key；正确是 `'through'`，见 `@wangeditor/editor` dist 的 genSimpleToolbarKeys:23929 与 group-more-style）。wangEditor 工具栏遇到非法 key 会在该位置中断渲染，导致其后的所有按钮不显示——与现象完全吻合。
- 修复（software-bugfix-editor-toolbar，全 PASS）：web/src/views/ComposeView.vue toolbarKeys 中 `'strikeThrough'` → `'through'`；`editorMode` 保持 `'default'`（否则 fontFamily/fontSize 不注册，字体/字号功能丢）。
- 回归（QA 严过关）：逐 key 核对 18 个功能 key 全部为 wangEditor 5.1.23 合法注册 key；`strikeThrough` 残留 0；editorMode=='default'；后端 scripts/verify_font_export.py 复跑 11/11 PASS。
- 经验：wangEditor v5 的删除线菜单 key 是 `'through'`，不是 `'strikeThrough'`；显式 toolbarKeys 里含非法 key 会让工具栏渲染在该处中断。default 模式下 justify*/indent 等被包在 group-* 对象里，但作为独立 key 仍合法可渲染。
