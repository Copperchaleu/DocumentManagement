## AI Agent 概念澄清（用户提问）
- Agent **本体是后端运行时代码**（编排器 + tool registry + llm gateway），不是一堆 markdown 自动跑起来。
- `docs/ai-agent-design.md` 是给人看的设计契约；WorkBuddy 的 `SKILL.md` 是另一套工作流说明书，与本业务 Agent 不是同一物。
- 编排 = while 循环：组消息 → 调 LLM → 若有 tool_calls 则执行 Python 函数 → 结果回灌再调 LLM → 直到自然语言回复。
- LLM 只负责选工具和填参；真正 CRUD/写 Word 由 tool handler 调 service 完成。
