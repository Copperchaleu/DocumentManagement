# 2026-08-02

## 本地文档管理系统 v1

- 技术栈：Python FastAPI + SQLite + python-docx + 纯静态前端
- 功能：粘贴文字→Word、分类 CRUD（绑定本地目录）、按周/月/季同时归档、附件上传、文档列表检索
- 启动：双击 `start.bat`（首次自动建 `.venv` 并装依赖），服务地址 `http://127.0.0.1:8765`
- 数据目录：`data/app.db` + `data/documents/<分类>/by_week|by_month|by_quarter/`

## start.bat 编码修复
- 根因：`start.bat` 曾以 UTF-8 + 中文 + LF 写出，中文 CMD 默认 GBK 解析导致整行命令被拆碎
- 处理：改为纯 ASCII + CRLF；补充同内容 `run.bat`（避免在 CMD 里敲 start 被内置 START 误伤）
- 经验：Windows 双击 bat 不要写 UTF-8 中文 echo

## 周规则 + 目录浏览
- 按周：ISO 8601，**周一到周日**；目录名 `YYYY-Www`
- 分类路径可选：`POST /api/browse-folder` 弹本机文件夹对话框（Windows Forms）
- 前端分类编辑弹窗新增「浏览…」按钮；粘贴页显示本周起止日期

## v2 多级分类 + 项目合并
- 模型：categories 树（parent_id）+ projects + period_files + attachments
- 项目只挂叶子分类；同一叶子分类+时间周期 → 一个合并 Word
- Word 路径：`{叶子目录}/by_week|by_month|by_quarter/{label}/{分类}_{period}_{label}.docx`
- 前端新增：项目列表、周期文件、定时草稿保存（默认 30s）
- 旧 documents 模型废弃；`/api/documents` 仅兼容适配

## 前端排版结论
- 当前问题主要是 CSS 残缺/冲突，不必为排版立刻引入 React/Vue
- 本地单页工具优先修 CSS；若后续交互复杂度大增再评估轻量升级

## 静默启动
- `start.bat` / `run.bat` / `start.ps1`：用 `pythonw.exe -m backend.main` 后台启动，不常驻 CMD，防误关
- 新增 `stop.bat`：按端口 8765 LISTENING 结束进程
- 首次建 venv/装依赖失败时用 mshta 弹窗提示（无控制台可读）

## Word 占用与重复保存修复
- Word 打开时保存：先 precheck 可写，返回 423 明确提示，不再只报 Internal Server Error
- 防重复：前端 saveBusy + 固定 project_id/token；失败重试复用同一项目，不新建多条
- Word 写入改为临时文件 + replace；锁定检测用 open/rename 探测
